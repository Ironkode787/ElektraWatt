# Brief RP3: a second signal lamp on an existing drawing

You maintain the drawing set of an expansion control cabinet, which is already open on folio 101, Power Supply 1 -
Main Current. The customer wants the heater's signal lamp E56 moved and a second lamp beside it, so that the heater's
state can be seen from two sides of the machine.

Run `{run}` is a `{kind}` run with the caps {turns} turns, {steps} steps, {looks} looks and {refusals} refused steps.

## The job

- Move the signal lamp E56 two columns to the right on folio 101; its wires stay connected.
- Add a second signal lamp in parallel with E56: its two connections on the same two potentials as E56's.
- Let the program route the wires of the two lamps again (Route selection), and look at what it drew: say in your
  notes where a wire runs as you would draw it and where it does not.
- Run the check and look at what it says about your change.
- Export the PDF of the drawing set and leave the project saved.
