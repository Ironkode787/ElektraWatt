# Brief RP3: a second signal lamp on an existing drawing

You maintain the drawing set of a control cabinet, which is already open on folio 102, the 24 V control circuit. The
customer wants the contactor's signal lamp moved and a second lamp beside it, so that the contactor's state can
be seen from two sides of the machine.

Run `{run}` is a `{kind}` run with the caps {turns} turns, {steps} steps, {looks} looks and {refusals} refused steps.

## The job

- Move the signal lamp beside the contactor's coil two columns to the right on folio 102; its wires stay connected.
- Add a second signal lamp in parallel with it: its two connections on the same two potentials as its own.
- Let the program route the wires of the two lamps again, and look at what it drew: say in your
  notes where a wire runs as you would draw it and where it does not.
- Run the check and look at what it says about your change.
- Export the drawing set as one printable document file and leave the project saved.
