# Draw a reusable supply block

A new cabinet project is open. Your team needs a reusable symbol for the supply block in the reference picture
provided with this run, `frames/reference.png`. Draw it from that picture; do not import an existing symbol.

- Include the five numbered plug pins, their printed supply labels and the separate earth connection on the right.
  Name that sixth electrical connection FE. Preserve the relative layout; you may resize it to put all electrical
  connections on the native 4 mm grid.
- Give the symbol a name and the new library key `example.supply-block`, with suitable electrical function data.
  Include a device-tag text field and a cross-reference anchor.
- Check its rotated and mirrored views. Correct any validation errors before saving it to `symbols.ewlib`, a name
  without a folder, which the editor keeps in your user library folder.
- Put a test copy on a page in the open project. Save the project and leave it ready for someone else to wire.

The drawing should remain editable and reusable. In your hand-back say whether you completed the job, needed hints,
or could not finish, and describe any confusing or missing controls. Do not substitute a different symbol just to
finish. If you cannot make a detail, record that limitation honestly.

This is a development playtest. A separate run on the release candidate is required for the release gate.
