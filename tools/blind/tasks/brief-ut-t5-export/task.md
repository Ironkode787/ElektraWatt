# Task T5: export the drawing set

You are working on an existing project for a control cabinet, which is already open. The customer wants the drawing
set as a PDF, and the wireman asks where the 24 V output 24VDC-1 of folio 102 goes next.

Run `{run}` is a `{kind}` run with the caps {turns} turns, {steps} steps, {looks} looks and {refusals} refused steps.

## The job

Export the drawing set and show where 24VDC-1 on folio 102 continues.

- Export the whole drawing set as one PDF file next to the project.
- Then show the wireman the continuation of 24VDC-1: start at its interruption point on folio 102 and go to where it
  continues.
- Change nothing in the drawing.
