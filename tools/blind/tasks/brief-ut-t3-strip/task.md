# Task T3: edit a terminal strip

You are working on an existing project for a control cabinet, which is already open. The terminal strip -X1031 of the
pneumatics supply has twenty terminals; twelve of them are spare and still carry the function texts of the circuits
they were once meant for.

Run `{run}` is a `{kind}` run with the caps {turns} turns, {steps} steps, {looks} looks and {refusals} refused steps.

## The job

Insert a terminal between -X1031:4 and :5, then set the function text of all spare terminals to "Reserve".

- The new terminal sits between terminal 4 and terminal 5 of -X1031 and gets a designation no other terminal of the
  strip has.
- Every spare terminal of -X1031 then has the function text `Reserve`.
- Set the texts in one go, as you would for many terminals, if the program lets you.

Leave the project saved when you are done.
