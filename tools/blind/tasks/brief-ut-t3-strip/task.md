# Task T3: edit a terminal strip

You are working on an existing project for a control cabinet, which is already open. The terminal strip -X1021 of the
24 V supply has eight terminals in two bridged groups, the 24V on terminals 1 to 4 and the 0V on terminals 5 to 8; the
terminals have no function text yet.

Run `{run}` is a `{kind}` run with the caps {turns} turns, {steps} steps, {looks} looks and {refusals} refused steps.

## The job

Insert a terminal between -X1021:4 and :5, then set the function text of the four 0V terminals to "0V".

- The new terminal sits between terminal 4 and terminal 5 of -X1021 and gets a designation no other terminal of the
  strip has.
- The terminals 5 to 8 of -X1021 then have the function text `0V`.
- Set the texts in one go, as you would for many terminals, if the program lets you.

Leave the project saved when you are done.
