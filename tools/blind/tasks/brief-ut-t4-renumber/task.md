# Task T4: renumber the folios of a section

You are working on an existing project for a control cabinet, which is already open. Section 1 of the drawing set has
gaps between its folios, which an old numbering in steps of two left behind, and the customer wants them closed: the
section starts at folio 101 and goes on in steps of one.

Run `{run}` is a `{kind}` run with the caps {turns} turns, {steps} steps, {looks} looks and {refusals} refused steps.

## The job

Renumber section 1 so that its folios are 101 to 105. Check what changes before you apply it.

- Before you apply the change, look at what it will change: the tags, the cross-references and the folios.
- After it, the motor cable on the folio of the motor is -103W1 again.

Leave the project saved when you are done.
