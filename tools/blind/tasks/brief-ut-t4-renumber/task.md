# Task T4: renumber a folio

You are working on an existing project for a control cabinet, which is already open. Section 1 of the drawing set has
folios 101, 102, 103 and 106: the folios 104 and 105 were dropped long ago, and the customer wants the gap closed.

Run `{run}` is a `{kind}` run with the caps {turns} turns, {steps} steps, {looks} looks and {refusals} refused steps.

## The job

Folio 106 should become 104. Check what changes before you apply it.

- Before you apply the change, look at what it will change: the tags, the cross-references and the folios.
- After it, the cables of the old folio 106 carry tags of folio 104.

Leave the project saved when you are done.
