# Task T2: wire a circuit breaker

You are working on an existing project for a control cabinet, which is already open. On folio 102 a colleague has just
put the 16 A miniature circuit breaker -102F1 back between the 24 V power supply -102G1 and the load distribution
-102F2, but it has no wires yet.

Run `{run}` is a `{kind}` run with the caps {turns} turns, {steps} steps, {looks} looks and {refusals} refused steps.

## The job

Connect the breaker's input to both + outputs of the power supply, and its output to both 24 V inputs of -102F2.

- -102G1 has two + outputs; both go to input 1 of -102F1.
- Output 2 of -102F1 goes to both 24VDC inputs of -102F2.
- When you are done, none of these connection points is left unconnected.

Leave the project saved when you are done.
