# The crate map

Generated by `cargo xtask gen-maps` (`xtask/src/crate_map.rs`) from the manifests, the tiers of `ci/dep-rules.toml` and the head comments; do not edit it. Every workspace crate, by folder: the first sentences of its crate comment, its licence, its tier, the workspace crates it depends on, the ones that depend on it and the ones whose tests alone do; under it each file of its `src/` with the first sentence of its head comment, marked large above 1,000 lines (read it by range). The rules on these edges are in `ci/dep-rules.toml` and [the architecture](../design/04-architecture.md) §3.

## ew

`bin/ew` · GPL-3.0-or-later · tier programs · depends on `ew-api`, `ew-print` · used by none · in tests by none

The `ew` command line as a library: [`run`] parses the arguments, runs the subcommand on the streams and the environment it is given ([`Io`], [`Env`]) and returns its exit code. The program (`main.rs`) runs it on the process's own; the tests of `bin/ew` run it on buffers and a test folder's environment, and start the program as a process only for what a process is: its exit, the merge driver git runs, a piped standard input.
