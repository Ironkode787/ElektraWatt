# M2.5: back on track

**Status:** running · **Started:** 2026-11-09 · **Base:** `5516edba4` (0.1.0 is `v0.1.0`)

M2.5 builds no features and fixes no behaviour. It leaves a project that is lean to work in: less code to carry,
one source for every list, documents that say what is true today, and a development loop of one command. M2.5-Fix
follows it and makes the program work properly; M3 is new development.

This file is the plan, the log and the exit record of M2.5. It replaces the M2.5 row of the global plan.

## Principles

1. **Delete before fixing, fix before adding.** A check, list, document or abstraction stays only when someone can
   say what it caught or who reads it.
2. **One source.** Anything listed twice is generated or derived from one of the two, or one of them goes.
3. **Behaviour does not change.** Golden A, the acceptance tests and the snapshots stay byte-equal through M2.5:
   they are the proof of every move. A fix that changes behaviour waits for M2.5-Fix.
4. **Proportion.** This is an early alpha of a desktop tool with one developer and one pilot. Machinery that suits
   a released product with a team waits for 1.0, in git history, not in the tree.
5. **History stays in git.** Nothing is "archived" in the tree. What leaves is found at `5516edba4`.
