# M2.5-Fix: a properly working program

**Status:** running · **Started:** 2026-11-11 · **Base:** `03848ea6b` · **Release:** 0.2.0

M2.5-Fix builds no new features. It fixes what stops the work in hands-on use, until the wizard, a new project,
placing, wiring, routing, the symbol editor and the QET import work as a whole. The open rows are in
[backlog.md](backlog.md); a finished row is deleted there. M3, new development, follows.

**The gate** is the owner's own hands-on test of a release candidate. A persona round of three or four runs comes
before it. A passing suite is not the gate.

## How a fix is made

1. **Reproduce first.** A row states what a person saw. Before a line changes, the fault is shown in a test or in an
   offscreen render, and the row's reading of the cause is checked: the first row of this milestone named a router
   fault that was a fault of its test.
2. **Through the window.** A fix for something found by hand gets its test on the window's own path: the pointer
   and the keys in `ew-ui`, not a dispatched action. The owner's findings of rc.3 were all in what the tests of
   dispatched actions do not reach.
3. **The whole flow.** A row about a flow (a symbol from the editor onto a page) is done when the flow ends where the
   person wanted to be, not when one step of it passes.
4. **Delete before you fix.** Where a control cannot be made to work in this milestone, it goes from the window
   or says in words why it does nothing. Nothing inert stays.
5. **Checks.** `cargo xtask check -p` on the crates a fix reaches. The whole workspace and the deep run at the
   exit.

- **Step 1, FT-1643** (a drawn symbol never reaches a page). Walked in an offscreen window as the owner did: a new
  symbol had no key, the key's field is on another tab, and Save to library and Test on a new page were refused
  without a word, because the editor left the refusal to the Validation list and the window left it to the editor.
  With a key typed the whole flow worked. Now a symbol's key is made from its name until one is typed, a refused
  action says why under the symbol's name, Save says where the symbol went, a second symbol of the same name takes
  the next free key, and a changed symbol is saved as the next patch version instead of a refusal. A drag draws a
  line, a circle, an ellipse and an arc as it drew a rectangle. The flow has a test by the pointer alone.
- **Step 1, FT-1642 and FT-1641** (Select could not move or delete a connection point; no ghost, no arrow keys).
  The editor's Select tool picked graphics only. It holds a shape, a connection point, a text slot or a link point
  now: a drag moves it and shows its outline where it will land, an arrow key moves it one step, Delete removes it.
  A connection point moves on the connection grid, so a move cannot put it off the grid. Tested by the pointer and
  the keys.
- **Step 1, FT-1653** (many starter symbols do nothing when clicked). A census of the Insert symbol list on a new
  project: of 33 starter symbols, seven were refused when chosen ("Give a letter code"), and the window shows no
