# Explanation

Explanation gives the background: why EW is built the way it is, what ideas its parts rest on, which alternatives were
rejected. It does not tell you what to type; the [tutorials](../tutorials/index.md) and
[how-to guides](../how-to/index.md) do that.

The design of EW is written down in documents that live in the repository, beside the code. They are the explanation
of record, and this section links to them instead of copying them, so that there is one text to keep correct.

| To understand | Read |

| the entities of a project: devices, functions, terminals, potentials, cables | [Domain model](https://github.com/Ironkode787/ElektraWatt/blob/main/docs/design/03-domain-model.md) |
| how the program is built: the model, commands, derived data | [Architecture](https://github.com/Ironkode787/ElektraWatt/blob/main/docs/design/04-architecture.md) |

| how potentials, terminals and cables connect | [Connections, terminals, cables](https://github.com/Ironkode787/ElektraWatt/blob/main/docs/design/08-connections-terminals-cables.md) |
