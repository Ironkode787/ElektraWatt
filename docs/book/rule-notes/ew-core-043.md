## What it checks

A placeholder part: a part copy whose part number is TBD. One finding per placeholder copy, naming every device that
uses it. A warning online and an error in release mode: an open item that blocks release.

## Why

A placeholder marks a part that is not chosen yet. It must be replaced before the documentation is released.

## Standard

No standard: a project-hygiene rule.

## Example

On Golden A the TBD bridge, end bracket, rail and duct are placeholders.

## How to fix

Assign the real part on the Parts row of every device that uses the placeholder. There is no quick fix.

## Waiving

Do not waive it for a release; replace the part. While drawing, the finding is only a warning.
