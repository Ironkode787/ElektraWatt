## What it checks

A free text whose size is not one of the project's text styles, such as a size an import kept. One finding per text,
shown on the page; online only.

## Why

Text styles keep sizes consistent and let the project change them in one place. A free size escapes both.

## Standard

No standard: a project-hygiene rule.

## Example

Import a QElectroTech project with a text of a free font size.

## How to fix

The text style is on the text's row in the property grid. There is no quick fix.

## Waiving

Waive it for a text that must keep its size, such as a copy of a nameplate.
