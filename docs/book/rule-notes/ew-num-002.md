## What it checks

A frozen wire number that differs from the number the numbering rule gives the wire. A wire the rule does not number
(a cable core, a wire on no page) has no rule value and deviates. One finding per connection.

## Why

A frozen number stays when the drawing changes. When it no longer matches the rule, the wire list mixes two numbering
schemes.

## Standard

No standard: a project-hygiene rule.

## Example

In a new project, freeze a wire's number, then move the wire to another page.

## How to fix

The frozen flag is on the wire's number row in the property grid. There is no quick fix.

## Waiving

Waive it when the frozen number is printed on existing wiring and must stay.
