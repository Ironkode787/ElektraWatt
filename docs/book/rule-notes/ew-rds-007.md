## What it checks

A device whose letter code contains I or O, or whose class letter the project's identifier set reserves. Codes that
are not one to three capital letters, and terminals, are left out. One finding per device, with every reason.

## Why

I and O are easily read as 1 and 0. The 2019 classes also reserve letters for later use, so a code built on them may
mean something else later.

## Standard

- IEC 81346-2:2019, Table 2 (unverified)

## Example

In a new project, give a device the letter code KO.

## How to fix

Choose another letter code without I and O, and avoid reserved class letters.

## Waiving

Waive it for a letter code that the customer prescribes.
