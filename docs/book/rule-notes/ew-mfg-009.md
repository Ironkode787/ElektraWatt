## What it checks

A wire end set by hand that does not fit: its ferrule part is made for another size than the wire's, it is a twin
ferrule that no second wire on its clamp shares, or its ferrule part has another colour than the workshop stock's
ferrule for that end. One finding per end.

## Why

An end set by hand stays as it was set when the wire changes. A ferrule of another size does not hold the wire; a twin
ferrule needs two wires; a shop that marks sizes by the collar colour would read the wrong size.

## Standard

No standard: a project-hygiene rule.

## Example

In a copy of the sample project, set the To end of 101.4 in the Connections table to a twin ferrule: no second wire on
-101G1:PE shares it.

## How to fix

Reset the end to the rule: the quick fix clears the end set by hand. Or choose a part of the wire's size, or set the
other wire on the clamp to a twin ferrule as well.

## Waiving

Waive it where the shop makes the end so on purpose, and say why.
