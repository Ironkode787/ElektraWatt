# Release checklist: v0.3.0-rc.4

[The release checklist](../../checklist.md), copied and filled for the fourth candidate of 0.3.0. The fourth candidate is the third with one change: the release script shortens notes that are longer than GitHub takes as a release's text. The program is the third candidate's, commit for commit; the checks below were run on the third candidate's tree, and since then only `ci/release-verify.py` (its own test passes), the release procedure and this dossier changed. There is no CI
until 1.0 and the release workflow has an early alpha's size, so each item says what was run by hand and what was
not. An item that is not met is on record here for the owner's go; it is not hidden by a passing suite.

**Candidate:** `v0.3.0-rc.4` · **Commit:** the commit of `release/0.3` that the tag names · **Draft:** the draft
prerelease `v0.3.0-rc.4` on the repository's releases page · **Filled by:** the release manager ·
**Date:** 2026-11-18

| Item | Check | Signed by | Result and evidence |
|---|---|---|---|
| RC-01 | The threat model reviewed for this release | — | **Not done.** No review entry for 0.3.0. The release adds no network code. It adds readers of files from outside: EPLAN EDZ archives and parts XML, EPLAN report workbooks, DXF, AutomationML and the TIA tag workbook, and it runs a converter program that the user installs and names for DWG (in a private folder, removed on every way out). Each reader is bounded as the earlier ones are and has files in the hostile corpus, which passes; none was reviewed against the threat model. The changes since the second candidate add no reader of outside files and no network code; three fonts are bundled as files; F1 opens a page of the installed guide in the system's browser, as the Guide buttons did |
| RC-02 | No open fuzz crash; at most 10 quarantined tests | The release manager | **Met for what runs by hand.** The deep run (`cargo nextest run --workspace --all-features --run-ignored only`) passed on the release branch with the private corpus: it holds the long command fuzz, the oracle on every read, the acceptance gate and the long recordings. The hostile-corpus test passes in the whole-workspace check. No test is quarantined: every ignored test is a test of the deep run |
| RC-03 | Advisory waivers dated; SQLite's bundled version clean | The release manager | **Met.** `deny.toml` and `.cargo/audit.toml` both have `ignore = []`, so there are no waivers. `cargo deny check advisories licenses bans` on the candidate's tree says "advisories ok, bans ok, licenses ok". No crate was added or changed since the second candidate (`Cargo.lock` is as it was); the three fonts added are files under the SIL Open Font License 1.1, recorded in `NOTICE` and `REUSE.toml` |
| RC-04 | `SECURITY.md` names the release and its support end | The release manager | **Met.** The supported-versions rows: "0.3.x — Yes, until the next minor release (0.4.0)", "0.2.x — No", "0.1.x — No" |
| RC-05 | The manual tests (RDP, screen readers, printers, network observation, the desktop installs, the crash offer) | — | **Not run for this candidate.** The owner tested the second candidate by hand on Windows and wrote sixteen points; this candidate answers them and waits for his test, which is the gate. The window's pictures were looked at offscreen at 1920 × 1080 and 2560 × 1440 only. Seven picture-led persona runs worked on the candidate's trees: five before the fix lanes (7, 7, 8, 7 of 10 on four jobs, 6 on a complete cabinet) and two after them (8 on the symbol editor, 7 on the cabinet); the last cabinet run met a panic at Fix all, which is mended and has its test, and no run was made after the last five fixes |
| RC-06 | The translation status meets NFR-I18N-01; the guide is in every installer | The release manager | **Met for the window and the tutorials.** `cargo xtask book-po` was run on the candidate's tree and its `--check` passes. `ci/translation-status.py` exits 0: the window's texts are 100.0 % nl-NL (7121 of 7121), the rule messages 100.0 % (545 of 545), the guide's introduction and tutorials 100.0 % (230 of 230); the rest of the guide is English (275 of 1425 messages of the whole guide are translated).
